# Raw data — NIWA

**Not used.** NIWA was evaluated in Fase 0 and explicitly rejected in
favour of Open-Meteo — it offered no coverage Open-Meteo lacks, while
adding account setup, request-based access for recent data, and no
date-range filtering on downloads. See `docs/data_sources.md` (section
"NIWA / Open-Meteo (Climate) — DECISION: Open-Meteo only, NIWA
dropped") for the full reasoning.

This folder is kept empty deliberately, as a record of that decision —
not because the evaluation is pending.
