# Processed data

Cleaned datasets, joined across sources by subzone/grid ID, ready for
analysis and modelling.

## Status

Fase 2 ingestion in progress. `parcels_linz.geojson` has been generated
by `src/01_ingest_linz.py` (LINZ Property Boundaries, 3-TA + 1 ha area
filter, 14,265 parcels) — not committed to git due to size, see
"Reproducing this data" below. S-map, LCDB, and climate ingestion scripts
are still to be added.

## Reproducing this data

Files in this folder are generated by running the scripts in `src/`
(e.g. `python src/01_ingest_linz.py`), not committed to git due to size.
Requires a `.env` with valid API keys — see docs/data_sources.md.
