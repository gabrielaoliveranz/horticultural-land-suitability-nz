# Processed data

Cleaned datasets, joined across sources by subzone/grid ID, ready for
analysis and modelling.

## Status

Fase 2 ingestion in progress. Two outputs generated so far:

- `parcels_linz.geojson` — `src/01_ingest_linz.py` (LINZ Property
  Boundaries, all 3 target TAs + 1 ha area filter, 17,400 parcels:
  Western Bay of Plenty District 11,028, Tauranga City 3,237, Ōpōtiki
  District 3,135).
- `terroir.db` (SQLite) — `src/02_ingest_soil_lcdb.py` +
  `src/03_ingest_subzones.py`, table `parcel_attributes` (keyed on
  `source_id`, not `parcel_id` — see script docstrings): soil_depth,
  soil_texture, soil_drainage, soil_order (94.5% match), lcdb_class_2023
  (99.7% match), and subzone (23.7% match — only parcels within
  Apophenia's 5 named subzones get one, by design). See
  `docs/methodology.md`, "Handling unmatched parcels (nulls)".

Neither is committed to git due to size — see "Reproducing this data"
below. Climate ingestion is still to be added.

## Reproducing this data

Files in this folder are generated by running the scripts in `src/` in
order (`python src/01_ingest_linz.py`, then
`python src/02_ingest_soil_lcdb.py`, then
`python src/03_ingest_subzones.py`), not committed to git due to size.
Requires a `.env` with valid API keys — see docs/data_sources.md.
