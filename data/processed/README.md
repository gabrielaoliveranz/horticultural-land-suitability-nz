# Processed data

Cleaned datasets, joined across sources by subzone/grid ID, ready for
analysis and modelling.

## Status

Fase 2 ingestion in progress. Two outputs generated so far:

- `parcels_linz.geojson` — `src/01_ingest_linz.py` (LINZ Property
  Boundaries, 3-TA + 1 ha area filter, 14,265 parcels).
- `terroir.db` (SQLite) — `src/02_ingest_soil_lcdb.py`, table
  `parcel_attributes`: parcel_id joined to soil_depth, soil_texture,
  soil_drainage, soil_order, and lcdb_class_2023 (99%+ match rate, see
  `docs/methodology.md`, "Handling unmatched parcels (nulls)").

Neither is committed to git due to size — see "Reproducing this data"
below. Climate ingestion is still to be added.

## Reproducing this data

Files in this folder are generated by running the scripts in `src/` in
order (`python src/01_ingest_linz.py`, then
`python src/02_ingest_soil_lcdb.py`), not committed to git due to size.
Requires a `.env` with valid API keys — see docs/data_sources.md.
